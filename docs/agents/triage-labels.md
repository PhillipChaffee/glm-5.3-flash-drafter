# Triage labels

Use these names when an installed skill refers to a triage role.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| Needs triage | `needs-triage` | A maintainer must evaluate the issue. |
| Needs information | `needs-info` | The reporter must supply missing information. |
| Ready for agent | `ready-for-agent` | The work is specified for an agent to execute. |
| Ready for human | `ready-for-human` | The work requires human implementation. |
| Will not act | `wontfix` | The work will not be performed. |

Wayfinder labels describe decision-ticket types. An unresolved design question
is not automatically ready for implementation. Skill-produced implementation
tickets do not need another triage pass.
