Configuration reference

One example, from input to output

Follow “sat” through
an attention sublayer with mHC.

The input sequence is “The cat sat.” We follow “sat” from its token embedding to its output hidden state.

A vector is an ordered list of numbers. A matrix arranges numbers in rows and columns. Each number is an element.

A token embedding is the vector looked up for a token. A hidden state is a token’s internal numerical representation.

A language model predicts the next token from the input sequence. The token embedding for sat stays the same regardless of the surrounding tokens. Its hidden state needs information from those tokens to help predict what comes next.

Attention lets sat use information from The and cat. This walkthrough explains why each operation helps build that hidden state. We stop at X1, before the later computation that predicts the next token.

This untrained example uses three elements per vector. The token embeddings and matrices below are fixed for the entire example.

Terminology: one concept, one term

The text, video, and Python example use these names consistently. Shared definitions live in the project glossary.

Input sequence
The ordered input tokens: The / cat / sat.
Token embedding
A vector looked up for a token. The rows of E are the three token embeddings.
Residual stream
A path that carries a vector through the model. Each row of X0 or X1 corresponds to one residual stream.
Hidden state
The numerical representation of a token. Here, X0 is the input hidden state and X1 is the output hidden state.
Input mapping a
Combines the residual streams into one vector before attention.
RMSNorm
Root mean square layer normalization. Its output for the input sequence is Z.
Value projection Wv
A linear transformation that produces the value matrix: V = Z @ Wv.
Identity matrix
A matrix that leaves its input vector unchanged.
Query vector q
Attention compares this vector with each key vector. Here, q belongs to sat.
Key matrix K
One key vector per input token, arranged as rows.
Value matrix V
One value vector per input token, arranged as rows.
Attention scores
The scaled dot products before softmax: q @ transpose(K) / sqrt(3).
Attention weights
The numbers returned by softmax. Each multiplies the corresponding value vector.
Attention output projection
The linear transformation after attention. It is an identity matrix in this example.
Attention output y
The weighted sum of the value vectors, followed by the attention output projection.
Residual mapping C
Mixes the residual streams along the residual path.
Residual contribution B
The residual path’s contribution to the output hidden state: B = C @ X0.
Output mapping b
Scales the attention output for each residual stream.
Attention contribution A
The attention path’s contribution to the output hidden state: A = b @ y.
Attention sublayer
The attention computation within a Transformer layer. This example applies mHC’s three mappings around it.

The mapping names follow the mHC paper. Our local symbols are a = H_pre, b = transpose(H_post), and C = H_res.

The Transformer paper supplies the attention terminology. A and B name the two contributions in this example’s equation X1 = B + A.

1. Start with “The cat sat”

A token is one unit of model input. In this example, each word is one token. A token identifier tells the model which token it received. Its number does not measure meaning or similarity.

A token embedding supplies a vector that the model can transform and combine. Training adjusts real token embeddings to help predict tokens. These example vectors are chosen by hand, with no assigned meaning for each element.

We follow the final token, sat. Its token embedding is [7, -8, 9].

Carry forward: sat’s token embedding and the input sequence The / cat / sat.

2. Initialize four residual streams

Four residual streams let one token carry different vectors across layers. The mHC mappings let those streams exchange information and receive different amounts of a sublayer’s output. This adds room for different representations without running attention separately for every residual stream.

At the model’s start, each token has one token embedding. Copying it gives every residual stream the same starting information. Copying adds no information yet. Different attention contributions can make the residual streams different in step 11.

Each residual stream carries one vector through the attention sublayer. Copy sat’s token embedding from step 1 into each of the four residual streams.

3. Apply the input mapping

The attention sublayer takes one vector per token, while X0 has four residual streams. The input mapping controls how much each residual stream supplies to that vector. This lets attention use information from all four streams at its existing vector size.

The residual path still has X0. Combining the streams for attention does not replace the saved input hidden state.

The input mapping combines the residual streams into one vector. Use this input mapping a with X0 from step 2:

[ 0.200   0.400   0.600   0.800 ]

The symbol @ means matrix multiplication. Each element of a multiplies the matching row of X0. Add the four resulting vectors:

u_sat = a @ X0
      = 0.2 × [7, -8, 9]
      + 0.4 × [7, -8, 9]
      + 0.6 × [7, -8, 9]
      + 0.8 × [7, -8, 9]
[ 14.000  -16.000   18.000 ]

For The and cat, use their token embeddings from step 1. Initialize four residual streams for each token, as in step 2. Apply the input mapping to each token.

Carry forward: the input-mapping output for each token. Keep input hidden state X0 saved.

4. Apply RMSNorm

The input mapping can change the overall size of a vector. RMSNorm reduces that size variation before the query, key, and value projections. Otherwise, larger inputs can produce larger attention scores even when their relative element patterns are the same.

RMSNorm divides every element by the same positive number. This keeps their relative pattern before any learned scale. The projections receive a more consistent input scale.

Use u_sat = [14, -16, 18] from step 3.

RMSNorm applies root mean square layer normalization. Use scale 1 for every element. Set epsilon to 0.000001.

Add epsilon to the mean of the squared elements, before taking the square root. This keeps RMSNorm’s final divisor, rms, nonzero even when every input element is zero. The divisor for averaging the squares remains 3, the number of elements:

rms   = sqrt((14² + (-16)² + 18²) / 3 + 0.000001) ≈ 16.083
z_sat = u_sat / rms ≈ [0.870, -0.995, 1.119]

Apply RMSNorm to the input-mapping outputs for The and cat from step 3.

Carry forward: RMSNorm output Z. Keep input hidden state X0 saved.

5. Compute the value matrix

Attention needs information to combine from each input position. A learned value projection lets the model choose combinations of elements to supply that information. Training can adapt those combinations for later layers. Without the value projection, this calculation combines the unchanged rows of Z.

Here, Wv is fixed for the example. Its numbers illustrate the transformation rather than a learned choice of useful information.

The value projection is a linear transformation that produces value vectors. Apply this value projection Wv to Z from step 4:

[  0.400   0.000  -0.200 ]
[  0.000   0.200   0.100 ]
[  0.100   0.100   0.000 ]

Compute the value matrix V = Z @ Wv. For sat, element 1 is approximately 0.870(0.4) + (-0.995)(0) + 1.119(0.1) ≈ 0.460.

6. Compute the attention scores

Attention needs a way to compare sat with each available input position. A query vector represents sat for that comparison. A key vector represents a position to compare against. Training can shape these comparisons through separate query and key projections.

Attention compares a query vector with a key vector to compute an attention score. Use identity matrices for the query and key projections, so Q = K = Z.

These identity projections demonstrate the calculation without learned comparisons. All three input positions are available to sat because they occur at or before it.

The query vector q for sat is the final row of Z from step 4:

[ 0.870  -0.995   1.119 ]

The key matrix K contains one key vector per input token. Its transpose, Kᵀ, exchanges rows and columns:

Kᵀ: transposed key matrix, with columns The / cat / sat
ElementThecatsat
10.463-0.7900.870
20.9260.987-0.995
31.3891.1841.119

A dot product multiplies matching elements, then sums them. Longer vectors can produce larger dot products because they sum more products.

Large differences between attention scores can make softmax assign almost all weight to one position. The attention weights then respond less to small changes during training. The square-root divisor offsets the effect of vector length before softmax.

The mean is the sum divided by the count. The mean square uses squared elements in that mean. The Transformer paper derives this divisor for independent query and key elements with mean zero and mean square one. Under that assumption, the dot product’s root mean square grows with the square root of the element count.

Here, the query vector has three elements. Compute each attention score as a query–key dot product divided by sqrt(3):

attention_scores = q @ transpose(K) / sqrt(3)

The: (0.870×0.463    + (-0.995)×0.926    + 1.119×1.389) / sqrt(3)
cat: (0.870×(-0.790) + (-0.995)×0.987    + 1.119×1.184) / sqrt(3)
sat: (0.870×0.870    + (-0.995)×(-0.995) + 1.119×1.119) / sqrt(3)

Using the unrounded elements gives these attention scores:

[ 0.598  -0.198   1.732 ]

Carry forward: these attention scores. Keep value matrix V from step 5.

7. Compute the attention weights

Attention needs weights that specify how much of each value vector to combine. Softmax turns the attention scores into positive weights with a fixed total of one. Larger scores receive more weight, while smaller scores can still contribute. That fixed total makes the result a weighted mean of the value vectors.

These attention weights apply to positions in the input sequence. They do not predict the next token. The model computes next-token probabilities later.

Use the attention scores from step 6.

Apply softmax to the attention scores. First, exponentiate each attention score. Next, divide each result by the sum of those results. This produces the attention weights:

[ 0.219   0.099   0.682 ]

The attention weights are positive and sum to one. Their order is The / cat / sat.

Carry forward: the attention weights and value matrix V from step 5.

8. Compute the attention output

The token embedding for sat alone contains no information about The or cat in this input sequence. The weighted sum of value vectors brings information from all three positions into sat’s attention output. The attention weights determine how much each value vector supplies.

This makes the attention output depend on the input sequence. A trained model can use that dependence to represent relationships between tokens. These chosen numbers demonstrate the information flow, not a learned interpretation of the sentence.

Multiply the attention weights from step 7 by the value matrix V from step 5:

y = attention_weights @ V
  ≈ 0.219 × [ 0.324,  0.324,  0.000]   ← The
  + 0.099 × [-0.197,  0.316,  0.257]   ← cat
  + 0.682 × [ 0.460, -0.087, -0.274]   ← sat

The attention output projection is an identity matrix in this example. It keeps the same numbers in the attention output y:

[ 0.365   0.043  -0.161 ]

The attention output projection acts on a vector’s elements. The output mapping in step 10 acts across residual streams. It produces one attention contribution per residual stream from the attention output y.

Save attention output y. Now follow the residual path from input hidden state X0, saved in step 2.

9. Apply the residual mapping

The residual path carries existing information past the attention calculation. Attention can then add information without having to recreate the entire input hidden state. Mixing lets each residual stream use information already held in other residual streams.

Across many layers, unconstrained residual mappings can repeatedly enlarge or shrink the carried values. The mHC constraint limits this mixing while allowing information to move between residual streams.

Use input hidden state X0 from step 2. Keep attention output y saved for step 10.

The residual mapping mixes the residual streams along the residual path. Use this residual mapping C:

10.5000.2500.1250.125
20.1250.5000.2500.125
30.1250.1250.5000.250

Compute the residual contribution B = C @ X0. For residual stream 1:

B₁ = 0.500 × [7, -8, 9] + 0.250 × [7, -8, 9]
   + 0.125 × [7, -8, 9] + 0.125 × [7, -8, 9]
   = [7, -8, 9]

Each residual stream in X0 carries the same vector. Each row of C sums to one. So the four rows of the residual contribution match:

[ 7.000  -8.000   9.000 ]
[ 7.000  -8.000   9.000 ]
[ 7.000  -8.000   9.000 ]
[ 7.000  -8.000   9.000 ]

The residual mapping C satisfies the mHC constraint:

  • All elements of C are nonnegative. Elements of X0 can still be negative.
  • Every row sums to one. Row 1 gives 0.500 + 0.250 + 0.125 + 0.125 = 1.
  • Every column sums to one. Column 1 gives 0.500 + 0.125 + 0.125 + 0.250 = 1.

A doubly stochastic matrix has nonnegative elements. Every row and every column sums to one.

Here, the mean is the sum of the four residual-stream vectors divided by four. The residual mapping preserves this mean.

Nonnegative elements and unit row sums make each output element a weighted mean of the corresponding input elements. It stays between their smallest and largest values.

Unit column sums keep each input residual stream’s total weight at one across the output residual streams. This preserves the mean across residual streams.

Manifold-Constrained Hyper-Connections (mHC) restricts the residual mapping to doubly stochastic matrices. Repeated doubly stochastic residual mappings keep these properties. Mixing can still reduce differences between residual streams.

The attention contribution can change the mean and the range in the output hidden state. The constraint controls residual mixing. It does not guarantee stability for the whole model.

Save residual contribution B. Attention output y remains available from step 8.

10. Apply the output mapping

Attention produces one attention output for sat, but the next sublayer needs four residual streams. The output mapping lets each residual stream receive its own amount of that attention output. Separate scales let the streams change differently while reusing one attention result.

Here, identical attention contributions leave the initially identical residual streams identical. The different scales in b let them become different. These scales are chosen for the example. They do not assign fixed jobs to the residual streams.

The output mapping scales the attention output for each residual stream. Apply this output mapping b to y from step 8:

[ 0.500 ]

[ 1.500 ]

For residual stream 1, 0.25 × y ≈ [0.091, 0.011, -0.040]. Residual stream 4 receives six times that attention contribution because 1.50 / 0.25 = 6.

The elements of the output mapping need not sum to one. The doubly stochastic constraint applies to the residual mapping C.

Carry forward: attention contribution A and residual contribution B from step 9.

11. Compute the output hidden state

Adding the two contributions lets attention modify the carried representation. The residual contribution supplies existing information from X0. The attention contribution supplies information from the input sequence through attention.

Without B, only the attention contribution remains. Without A, this update adds no information from attention. Their sum gives the next sublayer a hidden state that includes both paths.

The output hidden state is X1 = B + A. Add the residual contribution and attention contribution for each residual stream:

B₁ + A₁ ≈ [7.000, -8.000,  9.000]
        + [0.091,  0.011, -0.040]
        = [7.091, -7.989,  8.960]

The input sequence is still “The cat sat.” The residual streams in X0 carried identical vectors. In X1, they carry different vectors.

The rows of the residual contribution matched. The output mapping produced different attention contributions, so the residual streams became different.

The output hidden state X1 completes this attention sublayer with mHC. It contains all four residual streams for the next sublayer.

A trained language model continues through later sublayers. It then converts its final representation into next-token probabilities. That later prediction can use information gathered from the input sequence. Our numerical example stops at X1 and predicts no token.

The entire computation is:

X1 = C @ X0 + b @ Attention(RMSNorm(a @ X0))
     └───┘   └────────────────────────────┘
       B                   A

The attention path uses the same input sequence from steps 1–8. The residual path uses the input hidden state saved in step 2.
